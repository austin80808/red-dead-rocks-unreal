# red-dead-rocks-unreal

The Unreal Engine 5.8 project for Red Rocks: levels, materials and imported
meshes. Everything in `Content/` is generated by the scripts in
[red-dead-rocks](https://github.com/austin80808/red-dead-rocks) (`unreal/*.py`);
this repo is the saved result, so the level can be restored or rolled back.

- Main level: `Content/RedRocks/Lvl_RedRocks.umap` (also the startup map)
- Plugins enabled beyond the template: Python scripting, editor scripting,
  USD importer and Interchange OpenUSD (for the ml0w scan)

## Clone

```bash
git lfs install            # once per machine
git clone https://github.com/austin80808/red-dead-rocks-unreal.git
```

Every `.uasset` / `.umap` is stored in Git LFS and marked lockable: they're
binary, so two people editing the same level can't be merged. Lock before
editing a shared level: `git lfs lock Content/RedRocks/Lvl_RedRocks.umap`.

`Binaries/`, `Intermediate/`, `Saved/` and `DerivedDataCache/` are ignored:
Unreal rebuilds them on first open (expect a long shader compile).
